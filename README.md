# 📖 Overview

**KaguneX Flutter Builder** adalah bot Telegram profesional yang memungkinkan pengguna membangun aplikasi Flutter langsung dari file ZIP melalui GitHub Actions.

Bot akan:

- 📤 Menerima project Flutter (.zip)
- 🔍 Memvalidasi project secara otomatis
- ☁ Mengunggah project ke GitHub
- ⚙ Menjalankan GitHub Actions
- 📦 Menghasilkan APK atau AAB
- 📥 Mengirim hasil build kembali ke Telegram

Semua proses berjalan otomatis tanpa perlu menginstal Flutter di perangkat pengguna.

# 📦 Installation

Clone repository

```bash
git clone https://github.com/your-username/kagunex-flutter-builder.git
```

Masuk ke folder

```bash
cd kagunex-flutter-builder
```

Install dependency

```bash
npm install
```

---

# ⚙ Configuration

Buat file `.env`

```env
BOT_TOKEN=YOUR_TELEGRAM_TOKEN

OWNER_ID=YOUR_TELEGRAM_ID

GITHUB_TOKEN=YOUR_GITHUB_TOKEN
GITHUB_OWNER=YOUR_USERNAME
GITHUB_REPO=YOUR_REPOSITORY

GITHUB_BASE_BRANCH=main
GITHUB_WORKFLOW_FILE=build.yml
```
